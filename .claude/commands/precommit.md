argument-hint: [コミットの意図(省略可)]
---
コミット前チェックを実行してください。意図: $ARGUMENTS

1. 現状把握: git status と git diff(staged 含む)で変更の全体像を確認する。
   意図しないファイル(生成物・デバッグ出力・一時ファイル・無関係な変更)が混ざっていないか。
2. 検証の再実行: CLAUDE.md のプロジェクト固有コマンド(テスト・lint・型チェック)をいま実行し、
   結果を提示する。過去に通った記憶は証拠にならない。
3. 秘密情報チェック: diff に対して認証情報パターンを grep する。
   例: git diff HEAD | grep -inE '(api[_-]?key|secret|token|passw|BEGIN [A-Z]+ PRIVATE KEY|AKIA[0-9A-Z]{16})'
   ヒットしたら内容を確認し、疑わしければコミットを止めてユーザーに報告する。
4. 差分レビュー: 変更が大きい(目安: 100行超 or 3ファイル超)または重要箇所に触れる場合、
   adversary サブエージェントに diff をレビューさせ、重大指摘を解消してから進む。
5. コミット分割: 複数の論理変更が混ざっていれば分割を提案する。
   コミットメッセージは「何を」だけでなく「なぜ」が分かる形で提案する。
6. 上記が全て緑になってからコミットする。push は明示的に依頼された場合のみ。
